### 新增

- **图片存储与图床设置**：新增「设置 → 图片与图床」面板，可在「本地存储」与「云端图床」两种存储位置之间切换。
- **五类图床支持**：阿里云 OSS、腾讯云 COS、七牛云 Kodo、Gitee 码云，以及兼容 HTTP POST 表单上传的自定义接口（支持自定义请求头与响应 JSON 中图片 URL 的键路径）。
- **一键测试上传**：配置完成后可在面板底部直接测试，返回图片链接与耗时，或显示失败原因，便于排查参数。
- **失败自动降级**：上传失败时可自动回退保存到本地 `assets` 目录（默认开启，可关闭），保证图片不丢失。
- **粘贴 / 拖拽直传**：粘贴或拖拽图片时按当前存储位置自动选择上传或落盘，上传过程有状态提示。
- **配置随备份同步**：导出 / 导入设置备份时一并包含图床配置，换机后无需重新填写即可继续使用。

### 修复

- **Gitee 令牌链接**：修复「前往 Gitee 生成私人令牌」链接在桌面端点击无反应的问题，现在会用系统默认浏览器打开 Gitee 私人令牌页面。
