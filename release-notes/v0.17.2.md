## 本次更新

### 更新日志
- 更新对话框支持 Markdown 格式的更新说明：标题、列表、代码、表格、链接均可正常排版，并可一键「复制说明」。
- 已是最新版本时也能展开「本版更新说明」，附带发布日期与 GitHub Release 链接。
- 说明中的外链统一交由系统默认浏览器打开。

### 更新检查
- 「帮助 → 检查更新…」检测到新版时直接显示版本号，帮助菜单上带提醒圆点。
- 桌面端检查完成后会同步展示最新 Release 的更新说明和发布日期。

### 修复
- 修复桌面端点击外部链接没有反应的问题：工具栏 GitHub 图标、帮助 → 关于、欢迎页版本徽章、更新对话框，以及正文 / 表格 / HTML 块内的 Ctrl（macOS 为 Cmd）+ 点击链接，现在都会交给系统默认浏览器打开。

### 发布流程
- 更新说明改为随仓库维护（`release-notes/`），发版时自动写入 GitHub Release 正文与应用内更新提示，内容可回溯、可审阅。

## 升级方式
- 已安装用户：打开「帮助 → 检查更新…」按提示升级。
- 全新安装：在下方 Assets 下载对应平台的安装包（Windows / macOS Universal / Linux）。
