## 本次更新

这一版是自 v0.22.1 以来的一次大版本升级：Markdown 里的图终于能直接渲染、导出、复制，写作时的章节导航也更跟手，同时打磨了设置页与工具栏的细节。

### 新增
- **图表渲染**：支持 mermaid / flowchart / sequence 三种图表，写在代码块里即写即渲染，所见即所得。
- **图表导出与复制**：图表头部提供导出下拉，支持导出 PNG / SVG，或一键把图表复制成图片，方便直接贴进文档、PPT。
- **代码块一键复制**：代码块头部新增复制按钮，点击即复制代码内容，并给出成功反馈。
- **Markdown 语法速查**：帮助菜单「欢迎使用」改为「Markdown 语法速查」，并加入图表示例，方便上手新能力。

### 改进
- **大纲锚点高亮**：大纲标题随编辑区滚动自动定位高亮，切换章节改为平滑缓动滚动，不再硬跳；同时优化了条目间距、圆角与层级视觉。
- **表格轻量模式 + 富编辑恢复**：表格精简为轻量渲染，同时恢复富编辑能力，编辑体验更顺。
- **图表编辑细节**：保持语言与图表标签原生大小写；代码编辑聚焦时改用柔和光晕边框；导出下拉文案防止折行、自适应宽度并靠右对齐。
- **分割线更紧凑**：分割线改为思源式通栏 1px 细线，并压缩其上方空行，上下不再多出整行空隙。
- **导出后一键定位**：图表（PNG / SVG）与 HTML 导出完成后，右上角通知带「打开文件」「打开所在目录」按钮；HTML 导出结果也统一为该轻量通知形式。
- **设置页优化**：左侧分类（外观 / 文件与启动 / 配置 / 更新 / 关于）各配图标，一眼定位；「关于」不再展示源码信息；右上角仓库图标 hover 提示精简。
- **更新公告默认展开**：更新对话框在「已是最新版本」时直接展示当前版本更新说明，去掉了「收起本版更新说明」按钮。
- **工具栏对齐优化**：顶部「MDCraft」品牌与「文件 / 帮助」等菜单按钮统一在同一水平线上垂直居中。
- **新建文档引导提示**：新建空文档时在光标行显示「开始创作，或按 / 查看插入命令」，引导用 `/` 唤起插入命令面板。

### 修复
- **打开文件被误聚焦**：打开已有文件时不再把光标落到文档内容上，默认保持纯预览渲染；只有点击文档或新建空文档才聚焦（首行标题的 `#` 也不再因光标触碰而显示源码）。
- **大文档标题被截断**：大纲改用强制完整解析，修复长文档中标题识别不全的问题。
- **图表导出 / 复制在桌面端失效**：修复 WebView 下导出 PNG 时报「画布被污染」错误的问题（改用同源数据加载）；下载改为走系统保存对话框，桌面端可正常导出并定位到文件。
