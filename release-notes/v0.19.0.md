## 本次更新

本次是一次设置界面的大改版：设置面板重做为「左侧分类 + 顶部搜索」，新增更新与关于两页，并精简了菜单栏。

### 界面
- **设置面板重构**：左侧改为分类 tab（外观 / 文件与启动 / 配置 / 更新 / 关于），右侧顶部是全局搜索框。
- **设置项搜索**：按标题、说明与同义词匹配，中文支持「深色模式」这类不连续写法；结果按分类分组，点击直接跳到对应分类的该项并高亮闪烁定位，支持 ↑/↓ 选择、Enter 打开、Esc 退出搜索。
- **新增「更新」分类**：查看当前版本、检查更新、下载安装（桌面端）、跳转 GitHub Releases，并可展开当前版本的发布公告。
- **新增「关于」分类**：应用图标、品牌字标、版本、简介、技术栈与仓库入口；原先独立的「关于」弹窗已并入设置（帮助菜单的「关于 MDCraft」会直接打开设置里的该页）。
- **合并配置相关项**：「配置文件」与「配置备份」合并为一个「配置」分类，内部按分组区分。
- **文件树「打开方式」**：编辑器不认的文件（exe、pdf、无后缀等）单击不再擅自用默认程序执行，而是拉起系统原生的「选择应用」框，由用户自己选用什么程序打开。
- 面板尺寸与信息密度同步调整，分类切换与搜索结果之间可一键返回。

### 修复
- **双击设置弹窗不再缩放窗口**：双击弹窗标题栏会误触发窗口最大化，现已修正。
- **无后缀文件不再被编辑器当文本打开**：`LICENSE`、`Makefile` 这类没有扩展名的文件改由系统处理。
- **非文本文件双击不再误入重命名**：此前双击 exe 等文件会同时弹出选择框和内联重命名框。

### 精简
- **移除「视图」菜单**：其中的主题模式、配色主题、源码模式分别由工具栏右侧按钮、状态栏左下角开关承担，入口更直接，菜单栏只剩「文件 / 帮助」。
