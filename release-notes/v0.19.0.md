## 本次更新

本次包含一处修复、一次设置界面重构，以及一处菜单精简。

### 修复
- **自动更新签名校验**：更新包签名校验用的公钥此前是旧的一把（key id `E2FACD1D9E423AED`），与 CI 签名用的私钥不对应，会导致更新包验签失败、无法完成自动更新。现已换为正确的公钥（key id `FF6564A99C515539`）。
- **二进制文件双击不再误入重命名**：此前双击 exe 等文件会同时触发「打开方式」弹窗与内联重命名框，两者互相打架。

### 界面
- **设置面板重构**：左侧改为分类 tab（外观 / 文件与启动 / 配置 / 更新 / 关于），右侧顶部是全局搜索框。
- **设置项搜索**：按标题、说明与同义词匹配，中文支持「深色模式」这类不连续写法；结果按分类分组，点击直接跳到对应分类的该项并高亮闪烁定位，支持 ↑/↓ 选择、Enter 打开、Esc 退出搜索。
- **新增「更新」分类**：查看当前版本、检查更新、下载安装（桌面端）、跳转 GitHub Releases，并可展开**当前版本**的发布公告（按版本号取对应 Release 的说明）。
- **新增「关于」分类**：应用图标、版本、简介、技术栈与仓库入口；原先独立的「关于」弹窗已并入设置（帮助菜单的「关于 MDCraft」会直接打开设置里的该页）。
- **合并配置相关项**：「配置文件」与「配置备份」合并为一个「配置」分类，内部按分组区分。
- **文件树「打开方式」**：编辑器打不开的文件（exe、压缩包等）单击不再直接调用系统程序，改为弹出「打开方式」对话框，由用户自选：用默认程序打开 / 选择其它应用（系统「选择应用」框）/ 在文件夹中显示 / 复制路径；右键菜单同样新增「打开方式…」。
- 面板尺寸与信息密度同步调整，分类切换与搜索结果之间可一键返回。

### 精简
- **移除「视图」菜单**：其中的主题模式、配色主题、源码模式分别由工具栏右侧按钮、状态栏左下角开关承担，入口更直接，菜单栏只剩「文件 / 帮助」。

### 注意
- 公钥在编译期嵌入应用二进制，因此**只有本次及之后的版本**才带正确公钥。
- 若你所在环境是从旧版本自动更新上来的，且此前因验签失败无法更新，请直接到 GitHub Releases 页面下载本版本安装包覆盖安装。

## 升级方式
- 已安装用户：打开「帮助 → 检查更新…」按提示升级。
- 全新安装：在下方 Assets 下载对应平台的安装包（Windows / macOS Universal / Linux）。
