## 本次更新

本次是一个修复版本：修正自动更新校验使用的 minisign 公钥。

### 修复
- **自动更新签名校验**：更新包签名校验用的公钥此前是旧的一把（key id `E2FACD1D9E423AED`），与 CI 签名用的私钥不对应，会导致更新包验签失败、无法完成自动更新。现已换为正确的公钥（key id `FF6564A99C515539`）。

### 注意
- 公钥在编译期嵌入应用二进制，因此**只有本次及之后的版本**才带正确公钥。
- 若你所在环境是从旧版本自动更新上来的，且此前因验签失败无法更新，请直接到 GitHub Releases 页面下载本版本安装包覆盖安装。

## 升级方式
- 已安装用户：打开「帮助 → 检查更新…」按提示升级。
- 全新安装：在下方 Assets 下载对应平台的安装包（Windows / macOS Universal / Linux）。
