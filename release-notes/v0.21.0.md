## 本次更新

本次加入了 Windows 文件关联：装好后在资源管理器里双击 Markdown 文件就能用 MDCraft 打开，文件图标也换成应用图标。

### 新增
- **Markdown 文件关联**：安装包（NSIS setup.exe）会注册 `.md` / `.markdown` / `.mdx` 与 MDCraft 的关联，双击这类文件直接用 MDCraft 打开。
- **资源管理器里显示应用图标**：关联建立后，`.md` 文件在资源管理器中的图标改为 MDCraft 应用图标，文件类型列显示「Markdown 文档」。
- **支持带文件路径启动**：从资源管理器双击打开时，应用会接收该文件路径并直接打开对应文档（普通启动不受影响）。

### 界面
- **最近打开里的 Markdown 文件用应用图标**：与左侧目录树保持一致，Markdown 文档一眼可辨。
