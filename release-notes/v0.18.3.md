## 本次更新

本次是一个外观体系的整体重构：原来的 5 套「主题」拆成了**主题模式**（浅色 / 深色）与**配色方案**（13 套预设）两个互不干扰的维度。

### 破坏性变更（自动迁移，无需手动处理）
- 旧的 5 套主题（GitHub / Newsprint / Night / Pixyll / Whitey）不再使用，原「主题」入口已移除。
- 旧设置会自动迁移：Night → 深色 + 洁白配色，其余 → 浅色 + 洁白配色；设置备份文件导入旧版本时同样自动迁移。
- 「跟随系统」模式已移除：首次启动按系统偏好落成固定的浅色或深色，之后不再随系统变化。

### 新增
- **13 套配色方案**：洁白、雾灰、钛灰、钴蓝、青绿、暖黄、樱粉、VS Code、IDEA、Xcode、JetBrains、Cursor、Claude Code；每套都有浅色 / 深色两版，选项名称前带色块预览。
- **设置面板「外观」分区**：可直接切换主题模式（分段按钮）与配色主题（下拉选择）。
- 「视图」菜单拆出「主题模式」与「配色主题」两个子菜单，与工具栏按钮一一对应。

### 改进
- 工具栏拆成两个独立按钮：
  - 主题按钮：太阳 / 月亮图标，点击在浅色 ↔ 深色之间循环切换，图标带旋入入场动画（遵循系统的「减少动态效果」设置）。
  - 配色按钮：调色板图标，点击展开 13 套配色列表。
- 排版与配色彻底解耦：字体、字号、行高、内容宽度不再随主题变化，仍可在设置中单独覆盖。
- 配色切换保留整页交叉淡变过渡（支持 View Transition 的环境下）。
- 状态栏右下角改为显示当前配色方案名称。

## 升级方式
- 已安装用户：打开「帮助 → 检查更新…」按提示升级。
- 全新安装：在下方 Assets 下载对应平台的安装包（Windows / macOS Universal / Linux）。
