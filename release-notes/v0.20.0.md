## 本次更新

本次集中改进了更新流程：新版本不再藏在菜单角标里，而是主动在右下角提示；更新包改为后台下载，下载期间可以继续编辑，写完再确认安装。

### 更新
- **新版本主动提示**：启动后静默检查到新版本时，右下角弹出提示条，显示版本号、发布日期，可直接下载或查看更新说明；点「稍后」收起，同一版本不再重复打扰（下次启动仍会提示）。
- **后台下载**：下载不再占用更新弹窗，关掉弹窗照常编辑，右下角常驻进度条显示百分比与已下载大小。
- **下载与安装分离**：下载完成后进入「已就绪」状态，由用户确认再安装，不再下载完直接退出应用。
- **安装前自动保存**：安装会退出应用，此时会先把未保存的内容落盘；保存被取消则中止安装，避免内容丢失。
- **启动时自动检查更新开关**：设置 → 更新新增该项，可关闭启动时的静默检查，改为完全手动。

### 修复
- **目录树删除不再「点取消也删掉」**：删除确认改用应用内弹窗。此前调用的是浏览器原生确认框，在桌面端拿不到可靠的返回值，确认框看着弹出来了，后续删除动作却照常执行。
- **删除失败不再静默**：删除出错时错误信息显示在确认框内（此前用原生弹窗，桌面上经常看不到）。

### 界面
- **确认框重做**：与设置面板、更新弹窗同一套视觉（圆角卡片 + 顶部标题栏 + 底部按钮条），删除操作用危险色强调，附带完整路径提示；点击遮罩或按 Esc 均可取消。
