## 本次更新

本次围绕「更新流程」和「文件打开体验」做了一轮大改：更新不用再盯着进度条，Markdown 文件在系统里也能直接用 MDCraft 打开。

### 新增
- **Windows 文件关联**：安装后 `.md` / `.markdown` / `.mdx` 双击即用 MDCraft 打开，资源管理器里的文件图标也换成应用图标；应用已在运行时再双击别的文件，会在当前窗口开成新标签页，不会另开窗口。
- **新版本主动提示**：启动后静默检查到新版本时，右下角弹出提示条，显示版本号与发布日期，可直接下载或查看更新说明。
- **后台下载**：更新包在后台下载，下载期间可以关掉弹窗继续编辑，右下角常驻进度条显示百分比与已下载大小。
- **应用内提示**：失败与结果提示改为右上角堆叠展示（普通提示约 4 秒、错误提示约 7 秒自动消失，也可手动关掉），不再出现「点了没反应、错了也看不到」的情况。
- **Markdown 文件专属图标**：左侧目录树与「最近打开」里的 Markdown 文档改用应用图标，一眼可辨。

### 改进
- **下载与安装分开**：更新包下完不再自动退出应用，进入「已就绪」状态，由用户确认再安装；安装前会先把未保存的内容落盘，避免内容丢失。
- **启动时自动检查更新开关**：设置 → 更新新增该项，可关闭启动时的静默检查，改为完全手动。
- **最近打开点条目后自动收起**：选完文件或文件夹，列表立即折叠，把主界面让出来。
- **打不开的文件给出明确出口**：图片、程序、无扩展名等文件不再显示乱码，而是弹出「无法打开 xxx」提示，并提供「选择其他应用打开」入口。
- **弹窗样式统一**：各类弹窗的圆角、间距与措辞统一；欢迎页「新建文档」按钮改用品牌渐变，浅色 + 洁白配色下不再是一块生硬的黑白方块。

### 修复
- **目录树删除不再「点取消也删掉」**：删除确认改用应用内弹窗（此前用的确认框在桌面上拿不到可靠返回值，框子看着弹出来了，后续删除动作却照常执行）；删除出错时也会直接显示在确认框内。
