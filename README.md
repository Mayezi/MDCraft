# MDCraft

所见即所得 Markdown 编辑器。**快**（Tauri 2 + Rust，目标 <5MB）且**好用**（块级实时渲染）。

> 架构要点：Rust 核心与桌面壳解耦；编辑器内核基于 CodeMirror 6 decoration 实现块级实时渲染，单文档无预览窗分离。
>
> 设计参考：界面结构与交互思路参考了 [dbx](https://github.com/t8y2/dbx) 的优秀设计，MDCraft 是面向 Markdown 写作场景的独立实现。

## 技术栈

| 层 | 选型 |
| ---|--- |
| 桌面壳 | Tauri 2（系统 WebView，无捆绑 Chromium） |
| 核心后端 | Rust：`crates/md-core`（文件/搜索/监听，与壳解耦） |
| 编辑器 | CodeMirror 6 + Lezer + decoration 块级实时渲染 |
| 公式 | KaTeX（$ 行内 / $$ 块级，自定义 Lezer inline parser） |
| 图表 | Mermaid（按需懒加载，支持 mermaid / flowchart / sequence） |
| 前端 | React 19 + Vite 8 + Tailwind + zustand |
| 搜索 | ripgrep 内核（`ignore` + `grep-searcher` crate，进程内） |
| 主题 | CSS 变量多主题（主题模式 × 13 套配色方案） |

## 快速开始

```bash
pnpm install

# 浏览器模式（无需 Rust，立即可用）
pnpm dev        # http://localhost:5173

# 桌面模式（需要 Rust 工具链）
pnpm tauri dev

# 打包
pnpm tauri build
```

### 桌面构建环境要求

- Node.js ≥ 18、pnpm
- Rust ≥ 1.88（`rustup` msvc 工具链）
- Visual Studio Build Tools（含 "使用 C++ 的桌面开发" 工作负载）

## 目录结构

```
mdcraft/
├── src/                    # 前端（React + CM6）
│   ├── editor/             # 编辑器核心
│   │   ├── livepreview.ts  # ★ 行内/行级装饰（ViewPlugin）
│   │   ├── blocks.ts       # ★ 跨行块替换 + block widget（StateField + atomicRanges）
│   │   ├── markdown-config.ts # $ / $$ 公式、==高亮==、<u> 的 Lezer 解析扩展
│   │   ├── widgets.ts      # 表格/公式/图片/分割线/复选框/属性卡部件
│   │   ├── diagram.ts      # mermaid / flowchart / sequence 图表渲染与交互
│   │   ├── slash.ts        # 斜杠快速插入面板
│   │   ├── commands.ts     # 加粗/斜体/标题/表格等命令
│   │   └── setup.ts        # 扩展装配 + 源码模式切换（compartment）
│   ├── ui/                 # 菜单/文件树/大纲/标签页/状态栏/设置面板
│   ├── lib/                # 后端抽象（Tauri/浏览器双模式）、导出、图床、统计
│   └── styles/             # 主题变量 + editor.css 渲染样式
├── crates/md-core/         # Rust 核心（fsutil/workspace/search/watcher，不依赖 Tauri）
├── src-tauri/              # Tauri 壳（命令层，薄）
└── public/                 # 图标与静态资源
```

## 已实现

### 所见即所得渲染（行内按元素显源码）

- 行内标记默认隐藏；光标进入某个元素时显示该元素源码（加粗/斜体/删除线/行内代码/链接/`==高亮==`/`<u>` 下划线），移出后恢复渲染
- GFM 表格：思源式浮动工具条（增删行列、对齐方式、快捷删表）+ Obsidian 式行列拖拽重排 + 思源式列宽拖拽（记忆当前会话列宽），单元格内支持行内格式与 Enter / Tab 快捷扩展
- 图表支持：原生支持 `mermaid`、`flowchart`、`sequence` 代码块渲染（按需懒加载），自动渲染为矢量 SVG 图表，支持一键切换源码就地编辑；图表可导出为 PNG（2x 高清）或 SVG，也可一键复制到剪贴板
- 标题 H1–H6（字号分级；点击标题显示/编辑 `#`，H1/H2 下边框）
- 链接（点击显示完整 `[]()` 源码，Ctrl+点击打开）、图片（自动渲染 + 加载失败降级）
- 代码块（140+ 语言语法高亮 + 圆角背景 + 一键复制按钮）
- 任务列表（真实复选框，点击即切换 `[x]`；点击文字进入源码编辑）、无序列表圆点（按嵌套层级递减）
- 引用块（含嵌套层级竖线）、分割线、frontmatter 属性卡
- 行内 `$` 与块级 `$$` 公式（KaTeX 实时渲染；行内公式点击显源码，块公式保持渲染 + 浮层编辑）
- 块级元素（表格/围栏代码块/`$$` 公式块/Frontmatter/图表）整块渲染为部件，键盘导航当整体跨过（`atomicRanges`），点击才进入编辑——文档流里不出现源码

### 编辑器

- 快捷键：`Ctrl+B/I/K/E` 格式化，`Ctrl+1..6/0` 标题层级，`Ctrl+F/H` 查找替换（正则支持），`Ctrl+S` 保存，`Ctrl+Shift+S` 另存为，`Ctrl+N` 新建，`Ctrl+/` 源码模式
- 斜杠面板（`/` 快速插入，Notion/思源风格）：支持中文/拼音/英文关键字过滤，常用命令自动置顶；可插入标题、列表、引用、代码块、公式块、Mermaid 图表、流程图、时序图、表格、分割线、TOC、frontmatter 等
- 表格/公式原地编辑（方向键在单元格间进出，Esc/点击外部关闭）
- 图片：粘贴/拖拽自动处理（本地落盘到 `assets/` 或上传至图床，按设置自动切换）
- 自动保存（800ms 防抖 + 原子写）、本地草稿持久化
- 源码模式一键切换、自动配对、多光标、撤销历史
- 右侧缩略图（minimap，可在设置中开关）

### 界面

- 顶部菜单（文件/帮助，帮助菜单内置「Markdown 语法速查」指引）、多标签页、最近打开列表
- 文件夹树：打开文件夹后建树 + 文件监听（外部变更自动刷新），右键新建/重命名/导出/打开方式/打开文件位置/删除（应用内确认框 + 进系统回收站）
- 编辑器不认的文件（exe、pdf、无后缀等）单击弹系统「选择应用」框，由用户自己选程序打开；最近打开里遇到这类文件会先提示「不支持直接打开」并提供「选择打开方式…」
- 面包屑「定位」：在文件树中展开祖先目录并闪烁高亮当前文件
- 大纲面板：点击跳转 + 随编辑区滚动的锚点高亮（rAF 缓动滚动，不硬跳）
- 状态栏（行列/字数/字符/源码模式开关）、字数统计（CJK 按字、英文按词）
- 文内查找替换（中文面板，支持大小写/正则/全词匹配 + 匹配计数）
- 轻提示：失败与结果提示在右上角堆叠展示（应用内实现，不依赖原生弹窗），自动消失、可手动关闭
- 单实例窗口：双击 `.md` 文件在已有窗口中作为新标签页打开，不重复开窗

### 设置面板

左侧分类 tab + 右侧顶部全局搜索（支持中文/拼音/英文关键字，结果按分类分组，点击直达并高亮）：

| 分类 | 内容 |
|---|---|
| 外观 | 主题模式（浅色/深色）、配色方案（13 套）、正文字号、行高、正文宽度、缩略图开关 |
| 文件与启动 | 恢复上次打开的文件夹、目录树文件过滤 |
| 图片与图床 | 存储位置切换（本地/云端）、五类图床配置、一键测试上传 |
| 配置 | mdcraft.json 路径 + 定位、导出/导入设置备份（JSON） |
| 更新 | 当前版本与更新说明、检查更新、自动检查开关 |
| 关于 | 应用信息、技术栈、GitHub 链接 |

- **配色方案**：13 套预设，选项前带色块预览

| 钛灰 | `#48505d` | Xcode | `#0a84ff` |

### 图片与图床

支持两种图片存储方式，可在设置中随时切换：

- **本地存储**：粘贴/拖拽的图片自动保存到文档同级 `assets/` 目录，使用相对路径引用
- **云端图床**：粘贴/拖拽时自动上传至配置的图床，插入远程 URL

五类图床支持（纯前端签名，不依赖外部 SDK）：
1. **阿里云 OSS** — PostObject 表单签名，支持自定义 CDN 域名
2. **腾讯云 COS** — PostObject 表单签名
3. **七牛云 Kodo** — 客户端上传令牌生成，4 个上传区域可选
4. **Gitee 码云** — 基于仓库 API v5，支持自定义域名
5. **自定义 API** — 兼容任意 HTTP POST 表单上传接口，可配请求头与响应 JSON 路径

配置完成后可一键测试上传（返回链接与耗时）。上传失败时默认自动降级保存到本地 `assets/`（可关闭），保证图片不丢失。图床配置随设置备份一并导出/导入。

### 导出

- **PDF 导出**（桌面端）：思源式实时纸张预览 + 排版设置面板——纸张大小（A3/A4/A5/Letter/Legal/Tabloid）、横竖方向、页边距（默认/最小/无/自定义四边）、缩放（0.5x–1.5x）、主题（白底/跟随编辑器）、文档标题（自动/自定义）、按标题级别分页（H1–H4）、文字水印、页码、公式与图表完整保留
- **HTML 导出**：独立 HTML（内联样式 + KaTeX 自动渲染公式），入口在文件树右键（草稿在标签右键）
- **图表导出**：图表工具栏可单独导出为 PNG（2x 高清）/ SVG，或复制图片/SVG 代码到剪贴板

### 自动更新

- 桌面端：Tauri 签名校验 + 静默后台下载（不阻断编辑），下载完成后提示安装，安装前自动保存所有未保存文档
- 启动时可自动检查更新（可关闭），也可在设置面板手动检查
- 右下角非模态通知条，不打断编辑流程；每个版本只提醒一次
- 浏览器/开发模式下降级为 GitHub Releases API 跳转下载页

### Rust 后端

- 原子写（tmp+fsync+rename）、目录树、文件监听（notify 去抖批量推送）、删除走系统回收站

## 设计要点

- **单一数据源**：文档永远是无损 Markdown 文本，渲染只是"视图层装饰"——这是主流所见即所得编辑器验证过的路线，且规避了双向转换的语义丢失。
- **行内按元素显源码**：行内标记默认隐藏；光标进入某个元素时只显示该元素的 Markdown 源码（标记 / 链接地址 / 行内公式），移出恢复渲染。块级元素（表格/围栏代码块/`$$` 公式块/Frontmatter/图表）由 `touchesSelection` 判定是否进入编辑，编辑交由块级 widget / 浮层接管，文档流里不出现源码。
- **核心与壳分离**：`md-core` 不依赖 Tauri，未来 CLI/Web/MCP 形态直接复用。
